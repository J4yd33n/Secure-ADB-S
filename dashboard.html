ADS-B Cybersecurity — Airspace SOC

Real-time intrusion detection for ADS-B transmissions over Nigerian airspace. ADS-B is inherently unauthenticated and unencrypted — this IDS platform detects and classifies attacks before they endanger lives.

Why This Matters

  • ADS-B is unencrypted and unauthenticated — anyone with an SDR can inject false targets.
  • Ghost plane attacks can cause TCAS alerts, near-midair collisions, and controller overload.
  • Position spoofing can hide real aircraft from both radar and ATC simultaneously.
  • This IDS scores each event using ML-based anomaly detection to triage threats in <200ms.
  • Integration with MITRE ATT&CK framework for standardized threat classification.

Compliance & Standards

  • ICAO Annex 11 & Doc 10084 — CNS/ATM cyber protection framework
  • EUROCAE ED-202A — Airworthiness security for ADS-B systems
  • NIST SP 800-94 — Guide to Intrusion Detection and Prevention Systems
  • NCAA Nigeria Cybersecurity Policy — ATM systems protection mandate
  • ISO/IEC 27001 — Information security management alignment

Attack Types Detected

  • ADS_B_SPOOFING — False position broadcasts (MITRE T1583.001)
  • GHOST_AIRCRAFT — Fabricated flight targets (MITRE T1565.002)
  • POSITION_MANIPULATION — Drift/jump anomalies (MITRE T1565.001)
  • REPLAY_ATTACK — Replayed historical ADS-B frames
  • FLOODING — Message rate anomaly / DoS (MITRE T1498)
  • IDENTITY_THEFT — ICAO address reuse / hijack (MITRE T1584.002)
